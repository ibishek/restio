# Keyboard Shortcuts Cheat Sheet

RestIO is designed to keep your hands on the keyboard.

---

## Global Navigation & Windows

| Action                      | macOS Shortcut              | Windows / Linux Shortcut       |
| :-------------------------- | :-------------------------- | :----------------------------- |
| **Command Palette**         | <kbd>⌘</kbd> + <kbd>K</kbd> | <kbd>Ctrl</kbd> + <kbd>K</kbd> |
| **Keyboard Shortcuts Help** | <kbd>⌘</kbd> + <kbd>/</kbd> | <kbd>Ctrl</kbd> + <kbd>/</kbd> |
| **Close Modal / Dismiss**   | <kbd>Esc</kbd>              | <kbd>Esc</kbd>                 |
| **Toggle Sidebar**          | <kbd>⌘</kbd> + <kbd>B</kbd> | <kbd>Ctrl</kbd> + <kbd>B</kbd> |

---

## Request Operations

| Action                       | macOS Shortcut                  | Windows / Linux Shortcut           |
| :--------------------------- | :------------------------------ | :--------------------------------- |
| **Send Request**             | <kbd>⌘</kbd> + <kbd>Enter</kbd> | <kbd>Ctrl</kbd> + <kbd>Enter</kbd> |
| **Cancel In-Flight Request** | <kbd>Esc</kbd>                  | <kbd>Esc</kbd>                     |
| **Save Request**             | <kbd>⌘</kbd> + <kbd>S</kbd>     | <kbd>Ctrl</kbd> + <kbd>S</kbd>     |
| **New Request**              | <kbd>⌘</kbd> + <kbd>N</kbd>     | <kbd>Ctrl</kbd> + <kbd>N</kbd>     |
| **Close Active Tab**         | <kbd>⌘</kbd> + <kbd>W</kbd>     | <kbd>Ctrl</kbd> + <kbd>W</kbd>     |
| **Generate Code Snippet**    | <kbd>⌘</kbd> + <kbd>E</kbd>     | <kbd>Ctrl</kbd> + <kbd>E</kbd>     |

---

## Modal Dialog Keyboard Trapping

Inside any dialog (Command Palette, Environment Editor, Collection Runner, OpenAPI modal):

- <kbd>Tab</kbd> — Advance focus to next focusable element.
- <kbd>Shift</kbd> + <kbd>Tab</kbd> — Move focus backward.
- <kbd>Enter</kbd> — Submit or confirm active choice.
- Focus is strictly trapped inside the dialog surface and returns to your previous focused element when dismissed.
